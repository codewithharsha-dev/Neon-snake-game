🐍 Neon Snake Game

A modern take on the classic Snake Game, featuring a neon-inspired visual style and engaging gameplay. Control the snake, collect food, grow longer, and challenge yourself to achieve a new high score!

🎮 About the Project

Neon Snake Game is a browser-based game project created to bring the nostalgic Snake game experience to a modern interface. The project combines interactive gameplay with a vibrant neon theme.

It is also a practical project for learning web development, JavaScript game logic, user interaction, and responsive UI design.

✨ Features
🎨 Neon-inspired user interface
🐍 Classic snake movement and gameplay
🍎 Food collection and score tracking
📈 Snake grows as food is collected
💥 Collision detection and game-over logic
🎯 Interactive keyboard controls
🌐 Runs directly in a web browser

Note: Features may vary depending on the current implementation.

🛠️ Technologies Used
HTML5 — Structure of the game
CSS3 — Styling, layout, and visual effects
JavaScript — Game logic, movement, and interactions
🚀 Getting Started

Follow these steps to run the project on your local machine.

Prerequisites
A modern web browser
Git installed on your computer
Visual Studio Code (recommended)
Installation
Clone the repository:
   git clone https://github.com/codewithharsha-dev/Neon-snake-game.git

Navigate to the project folder:
   cd Neon-snake-game

Open the project in Visual Studio Code:
   code .

Open index.html in your browser, or use the Live Server extension in VS Code if your project uses separate HTML, CSS, and JavaScript files.
🎯 How to Play
Start the game.
Use the arrow keys to control the snake.
Collect food to increase your score and grow longer.
Avoid collisions with walls or the snake's own body, depending on the game rules.
Try to achieve your highest score!
Controls
Key	Action
⬆️ Arrow Up	Move up
⬇️ Arrow Down	Move down
⬅️ Arrow Left	Move left
➡️ Arrow Right	Move right
